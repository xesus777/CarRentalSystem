# CarRentalSystem

# Программный комплекс «Информационная система автоматизации сервиса проката автомобилей»

Данный программный продукт разработан в рамках учебной практики по направлению подготовки «Информационные системы и программирование». Приложение представляет собой настольную информационную систему (WPF), автоматизирующую процессы учета транспортных средств, ведения клиентской базы, контроля финансовых операций и аналитики аренды.

---

## Архитектура и стек технологий

* **Тип приложения:** Настольное приложение Windows (WPF — Windows Presentation Foundation)
* **Платформа:** .NET Framework 4.8 / .NET 8.0
* **Архитектурный шаблон:** Page-based Architecture (модульная навигация по страницам)
* **Технология доступа к данным:** Entity Framework
* **Система управления базами данных:** Microsoft SQL Server

## Функциональные модули системы

В соответствии с техническим заданием в рамках практики были спроектированы и реализованы следующие подсистемы:

1. **Модуль аутентификации и разграничения прав:**
   * Разделение интерфейса на 3 роли: Администратор, Менеджер, Клиент (и неавторизованный Гость).
   * Сквозное шифрование паролей алгоритмом SHA-256.
   * Подсистема защиты от несанкционированного подбора паролей: при 3-х неверных вводах сессия временно блокируется модулем проверки CAPTCHA.

2. **Модуль администрирования и учета автопарка:**
   * CRUD-операции (добавление, редактирование, просмотр, удаление) над объектами автопарка.
   * Подсистема загрузки графического контента: файлы изображений копируются в изолированный рабочий каталог `bin/Debug/cars/` с автоматической генерацией уникальных имен файлов для исключения конфликтов в файловой системе.

3. **Модуль интерактивного каталога:**
   * Поиск автомобилей по совпадению строк (Марка/Модель).
   * Фильтрация данных по категориям и классам авто.
   * Динамическая сортировка списка по стоимости суток.
   * Адаптивная верстка (динамический `ScrollViewer` для корректного отображения элементов при изменении геометрии окна).

4. **Модуль управления заказами и приемки:**
   * Модерация входящих заявок (одобрение/отклонение).
   * Регистрация возврата машин с линии проката с фиксацией дефектов и автоматическим направлением автомобиля в зону технического обслуживания (ТО).
   * Расчет штрафных санкций и удержаний средств (5%) при досрочной отмене бронирований.

5. **Модуль кастомизации и адаптивного дизайна:**
   * Реализация сквозных динамических ресурсов (`DynamicResource`) для поддержки светлой и темной тем оформления.
   * Полная русификация денежных и календарных форматов на уровне метаданных приложения (`ru-RU`).
   * Разработка кастомной подсистемы диалоговых окон (`CustomDialogWindow`) вместо устаревших системных `MessageBox`.
